# 爽阅

Flutter 打造的双端（Android / Windows）小说阅读器——内置固化书源、可导入书源引擎、本地书与在线书共用同一套阅读体验，离线能读，还能听。顶部住着一只会陪你长大的小兽。

静态主页：<https://leey1994.github.io/shuangyuebook/>

当前版本：**v1.2.1**

## 功能

### 桌宠「小墨」

* 顶部常驻一只书页精灵，随阅读时长自然成长：**墨滴 → 纸兽 → 墨狐 → 书灵**
* **全程同一个角色**：不管长到哪一形态，水滴头、页角耳、额头的朱红印都不会变，所以认得出是同一只
* 会呼吸、会眨眼；没人理它也**自己玩**——跳两下、翻身、伸懒腰、打哈欠、抖一抖
* 会沿顶部预留带**随机散步**，走路时整只按方向翻面（尾巴在身后）
* **按场景说话**：按时段问候、久别重逢、久坐护眼、摸鱼提醒，半透明气泡显示在身旁
* **61 种触发状态、300 多条台词**随机取用，同一个动作不会反复撞同一句
* 会关心人：深夜劝你睡、久坐提醒眼睛、长时间没来先问你还好不好；不催更、不施压
* 可在「设置 → 桌宠」一键关闭，不影响任何功能

### 书源

* 内置 **10 个固化书源**：顶点小说、速读谷、黄金屋、52书库、搬山人、神文小说、素书卷、篱笆好文学、小原文学、全本小说网。全部手写适配，随包发布，不依赖任何外部配置
* **书源引擎**：支持导入「阅读 3.0」格式书源，粘贴 JSON / 选择文件 / 订阅链接三种导入方式，可批量启停、删除与导出
* 固化书源与导入书源**完全同构**——搜索、发现、书架、阅读器、换源、离线缓存都不区分来源，可以随意混用
* **书源体检**：导入后自动批量检测，搜不出内容的书源直接移除，并逐条说明原因；此后每天首次启动自动体检一次，结果汇总在阅读记录页
* 搜索历史；发现页推荐 / 排行 / 书单聚合全部书源；导入书源的推荐与分类同样参与聚合
* 换源续读：当前源缺章时一键换源，按章节名自动匹配阅读进度

### 本地书

* 导入 **TXT / EPUB**：内置文件浏览器多选导入，也支持按常见目录批量扫描
* TXT 自动识别 UTF-8 / UTF-16 / GBK 编码，按章节标题模式自动分章
* EPUB 支持 EPUB2 与 EPUB3 双目录解析，自动抽取封面与书内插图
* 本地书与在线书共用同一套阅读、缓存、书签与统计
* 文件关联：在文件管理器里直接用爽阅打开 TXT / EPUB / 书源 JSON

### 阅读器

* **四种翻页方式**：滑动 / 覆盖 / 淡入 / 滚动。覆盖模式逐行对照「阅读 3.0」的手感实现，翻页吸附按固定速率收敛
* 排版可调：字号、行距、字距、左右边距、上下留白、首行缩进、正文字体（系统字体 / 霞鹜文楷）
* **6 种阅读背景**，页眉（章节名）与页脚（时间 / 页码 / 电量）分别开关
* 阅读时保持屏幕常亮；滑动到章末继续拖动即可直接进入下一章
* 书签、进度条、目录跳转，阅读进度自动记忆（重开继续）
* 设置面板分「排版 / 外观 / 听书」三页签，调参数时正文保持可见
* **进入阅读器优先读缓存**，弱网下不会长时间空转

### 听书

* 逐段朗读、自动跨章，段落高亮跟随；语速、音调可调
* 12 款在线音色：小臻、小瑜、晓晓（甜美女声）、云希（阳光青年）、云健（解说男声）、云夏（清亮少年）、晓伊（活力女声）、云扬（新闻播报）、晓北（东北味）、晓妮（陕西味）、晓曼（粤语女声）、云哲（台湾男声）
* 在线合成，结果本地缓存即开即读，断网自动回退系统语音

### 书架与记录

* 两种卡片样式：**长卡片 / 正方形卡片**，都带阅读进度条；列宽与间距自动计算，卡片间距与两侧留白完全相等，宽屏自动分列
* 六种排序（最近阅读、添加时间、书名、作者、进度、字数）× 正倒序
* 无封面时按书名稳定分配占位插画，不会每次刷新都换图
* 阅读记录：累计时长、连续天数、读完本数、最近 7 天柱状图，以及当天的书源可用情况
* 跨书书签总览，点一下跳回原文位置

### 全局联动

* **37 类操作**全部接入桌宠：翻章、书签、换排序、搜索、导入书源、换主题、朗读、清缓存……
* 每个动作都有对应的表情与台词；同一动作短时间内重复触发只涨成长值不刷屏

### 离线与其它

* 读过的章节自动落盘，断网无缝续读；支持整本下载、断点续传，随时暂停不白干
* 列表与封面本地缓存，冷启动秒开；缓存占用可视化，一键清理
* 搜索与发现页**实时出结果**：任一书源返回即刻上屏，不必等最慢的那个
* 安卓全程 edge-to-edge，顶部窄带就是状态栏本身那一行（原来显示时间 / 信号强度的位置）；窄带底色跟随阅读背景，不会割裂
* 实时公告：启动与运行中自动检查，新公告全屏直达（内容由 GitHub Pages 分发，改一处即全端生效）。公告写给还没更新的用户，升到对应版本后自动不再显示
* 自动更新：启动静默检查新版本，弹窗即更新公告；安卓一键安装，Windows 自动替换重启；下载多线路回退并校验完整性
* 桌面端独立窗口，窄屏 / 宽屏自适应布局

## 下载

Releases 页面提供 Android APK 与 Windows x64 绿色版。

正文字体「霞鹜文楷」**不随安装包分发**（一个字重就要 13MB，装包会大一半）。在阅读器「外观 → 正文字体」里点它会先询问是否下载，确认后从网络获取并长期缓存到本地；不下载则继续使用系统字体。安装包因此从 30.2MB 降到 22.4MB。

## 从源码构建

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
flutter build windows --release
```

桌面端的标题栏与桌宠活动区、顶部窄带这类只能肉眼确认的改动，可以用 `tool/shot.ps1` 启动桌面端并截图：

```powershell
powershell -ExecutionPolicy Bypass -File tool\shot.ps1 -Out build\shot.png -WaitMs 9000 -Dismiss
```

重新生成应用图标（各密度自适应图层 + 传统图标 + Windows ico）：

```powershell
powershell -ExecutionPolicy Bypass -File assets\icon\generate_icon.ps1
```
