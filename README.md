# 爽阅

Flutter 打造的双端（Android / Windows）小说阅读器——内置固化书源、可导入书源引擎、本地书与在线书共用同一套阅读体验，离线能读，还能听。

静态主页：<https://leey1994.github.io/shuangyuebook/>

当前版本：**v1.1.0**

## 功能

### 书源

* 内置 **10 个固化书源**：顶点小说、速读谷、黄金屋、52书库、搬山人、神文小说、素书卷、篱笆好文学、小原文学、全本小说网。全部手写适配，随包发布，不依赖任何外部配置
* **书源引擎**：支持导入「阅读 3.0」格式书源，粘贴 JSON / 选择文件 / 订阅链接三种导入方式，可批量启停、删除与导出
* 固化书源与导入书源**完全同构**——搜索、发现、书架、阅读器、换源、离线缓存都不区分来源，可以随意混用
* **书源体检**：导入后自动批量检测，搜不出内容的书源直接移除，并逐条说明原因；此后每天首次启动自动体检一次，结果汇总在阅读记录页
* 搜索历史；发现页推荐 / 排行 / 书单聚合全部书源；导入书源的推荐与分类同样参与聚合
* 换源续读：当前源缺章时一键换源，按章节名自动匹配阅读进度

### 本地书

* 导入 **TXT / EPUB**：内置文件浏览器多选导入，也支持按常见目录批量扫描
* TXT 自动识别 UTF-8 / UTF-16 / GBK 编码，按章节标题模式自动分章
* EPUB 支持 EPUB2 与 EPUB3 双目录解析，自动抽取封面与书内插图
* 本地书与在线书共用同一套阅读、缓存、书签与统计
* 文件关联：在文件管理器里直接用爽阅打开 TXT / EPUB / 书源 JSON

### 阅读器

* **四种翻页方式**：滑动 / 覆盖 / 淡入 / 滚动。覆盖模式逐行对照「阅读 3.0」的手感实现，翻页吸附按固定速率收敛
* 排版可调：字号、行距、字距、左右边距、上下留白、首行缩进、正文字体（系统字体 / 霞鹜文楷）
* **6 种阅读背景**，页眉（章节名）与页脚（时间 / 页码 / 电量）分别开关
* 阅读时保持屏幕常亮；滚动模式读到章末自动加载下一章
* 书签、进度条、目录跳转，阅读进度自动记忆（重开继续）
* 设置面板分「排版 / 外观 / 听书」三页签，调参数时正文保持可见

### 听书

* 逐段朗读、自动跨章，段落高亮跟随；语速、音调可调
* 12 款在线音色：小臻、小瑜、晓晓（甜美女声）、云希（阳光青年）、云健（解说男声）、云夏（清亮少年）、晓伊（活力女声）、云扬（新闻播报）、晓北（东北味）、晓妮（陕西味）、晓曼（粤语女声）、云哲（台湾男声）
* 在线合成，结果本地缓存即开即读，断网自动回退系统语音

### 书架与记录

* 三种视图（网格 / 小图 / 列表）× 六种排序（最近阅读、添加时间、书名、作者、进度、字数）× 正倒序
* 无封面时按书名稳定分配占位插画，不会每次刷新都换图
* 阅读记录：累计时长、连续天数、读完本数、最近 7 天柱状图，以及当天的书源可用情况
* 跨书书签总览，点一下跳回原文位置

### 离线与其它

* 读过的章节自动落盘，断网无缝续读；支持整本下载、断点续传，随时暂停不白干
* 列表与封面本地缓存，冷启动秒开；缓存占用可视化，一键清理
* 搜索与发现页**实时出结果**：任一书源返回即刻上屏，不必等最慢的那个
* 实时公告：启动与运行中自动检查，新公告全屏直达（内容由 GitHub Pages 分发，改一处即全端生效）
* 自动更新：启动静默检查新版本，弹窗即更新公告；安卓一键安装，Windows 自动替换重启；下载多线路回退并校验完整性
* 桌面端独立窗口，窄屏 / 宽屏自适应布局

## 下载

Releases 页面提供 Android APK 与 Windows x64 绿色版。

## 从源码构建

```bash
flutter pub get
flutter analyze
flutter test
flutter build apk --release --target-platform android-arm64
flutter build windows --release
```
