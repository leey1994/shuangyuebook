# 爽阅

> **爽快阅读，想看就看。**

Flutter 打造的双端（Android / Windows）小说阅读器——内置固化书源、可导入书源引擎、本地书与在线书共用同一套阅读体验，离线能读，还能听。顶部住着一只会陪你长大的小兽。

当前版本：**v1.0.3**（更新内容见 [docs/release-notes-v1.0.3.md](docs/release-notes-v1.0.3.md)）

静态主页：[https://leey1994.github.io/shuangyuebook/](https://leey1994.github.io/shuangyuebook/)

![爽阅 · 爽快阅读，想看就看](docs/assets/slogan.png)

## 功能

### 官网

* 极简单页，一条中性色阶、一种强调色，没有框架没有构建
* **版本号自动获取**：页面读 GitHub 最新 Release 的 tag，取不到退回公告文件，再退回页面默认值 —— 发一次版网页自己跟上，不用手改 HTML

### 桌宠「小墨」

* 顶部常驻一只书页精灵，随阅读时长自然成长：**墨滴 → 纸兽 → 墨狐 → 书灵**（养成周期按长期陪伴设计，第一阶约两周）
* **全程同一个角色**：不管长到哪一形态，水滴头、页角耳、额头的朱红印都不会变，所以认得出是同一只
* 会呼吸、会眨眼；没人理它也**自己玩**——跳两下、翻身、伸懒腰、打哈欠、抖一抖
* **阅读时钉在顶部预留带**（不打扰正文），**其它界面在整屏范围内自由溜达**，走路时整只按方向翻面（尾巴在身后）
* 会**绕开屏幕挖孔**（前置摄像头）；凑到摄像头附近还会探头看一眼
* 挖孔类型在「我的 → 桌宠 → 屏幕挖孔位置」里选：顶部居中 / 左上角 / 右上角 / 无挖孔
* **按场景说话**：按时段问候、久别重逢、久坐护眼、摸鱼提醒，半透明气泡显示在身旁
* **61 种触发状态、300 多条台词**随机取用，同一个动作不会反复撞同一句
* 会关心人：深夜劝你睡、久坐提醒眼睛、长时间没来先问你还好不好；不催更、不施压
* 可在「我的 → 桌宠」一键关闭，不影响任何功能

### 书源

* 内置 **13 个书源**（全部手写 Dart 原生适配，随包发布、不依赖任何外部配置）：顶点小说、速读谷、黄金屋、52书库、神文小说、素书卷、篱笆好文学、小原文学、全本小说网、鬼吹灯、抖音小说、伪速读谷、若雨中文
* **书源引擎**：支持导入「阅读 3.0」格式书源，粘贴 JSON / 选择文件 / 订阅链接三种导入方式，可批量启停、删除与导出。导入区**默认为空**，只放你自己挑的书源
* **网络获取书源**：内置 yiove 书源库、Xiu 精品、一程、破冰、关耳女频等公开合集直链（也可填任意订阅链接），一键「获取 → 全链路测试 → 导入可用源」——测试逐条跑搜索 / 目录 / 正文三段，坏源不进门；内置地址均经移动网络实测可直连，最慢 5.6 秒下完
* **引擎兼容性，全量实测驱动**：以 651 条合集书源（7 大合集去重）做真实网络全量探针，逐个修复此前静默失败的写法（模板表达式、XPath、CSS 排除 / 切片、JSONPath 过滤、`@put` / `@get` 变量、`@js:` 后缀降级、目录 / 正文翻页与净化）；修复后搜索可用源 38 → 107、详情 / 目录 5 → 22、发现页 43 → 77。完整报告见 `sources/阅读3.0书源兼容性测试报告.md`
* 固化书源与导入书源**完全同构**——搜索、发现、书架、阅读器、换源、离线缓存都不区分来源，可以随意混用
* **JS 引擎 + java.* 桥**：`@js:` / `<js>` / JavaScript 书源直接可用；`java.ajax` / `put` / `get`、DES / Base64 / `org.jsoup` 等常用调用内置兼容（晋江等强 JS 源全链路可读）；请求选项（`,{...}` 尾缀、POST body、header、编码）与 `@put` / `@get` **跨章持久变量**逐项对齐「阅读 3.0」
* **书源体检**：导入后自动批量检测，没通过的源逐条列出原因、删不删由你确认；此后每天首次启动自动体检一次，结果汇总在阅读记录页
* 搜索历史 + 热词；**排行页**热榜 / 好评榜 / 口碑榜 / 完结榜跨源聚合，去重合并、分类筛选，口碑榜按多源共同收录排序；首页推荐同样来自各源榜单
* 换源续读：当前源缺章时一键换源，按章节名自动匹配阅读进度

### 本地书

* 导入 **TXT / EPUB**：内置文件浏览器多选导入，也支持按常见目录批量扫描
* TXT 自动识别 UTF-8 / UTF-16 / GBK 编码，按章节标题模式自动分章
* EPUB 支持 EPUB2 与 EPUB3 双目录解析，自动抽取封面与书内插图；**多级目录按层级展示**——卷行加粗、章按层级缩进，长书一眼看清结构
* 本地书与在线书共用同一套阅读、缓存、书签与统计
* 文件关联：在文件管理器里直接用爽阅打开 TXT / EPUB / 书源 JSON

### 阅读器

* **四种翻页方式**：滑动 / 覆盖 / 淡入 / 滚动。覆盖模式逐行对照「阅读 3.0」的手感实现，翻页吸附按固定速率收敛
* 排版可调：字号、行距、字距、左右边距、上下留白、首行缩进
* **6 种阅读背景**，页眉（章节名）与页脚（时间 / 页码 / 电量）分别开关
* 阅读时保持屏幕常亮；章末轻划**松手即进下一章**（整章拖着滑也可），翻页越界自动回弹不卡半屏
* **安卓音量键翻页**：音量下 = 下一页、音量上 = 上一页；按住不连翻、音量条不弹，听书时自动让位给系统音量
* 书签、进度条、目录跳转，阅读进度自动记忆（重开继续）
* 设置面板分「排版 / 外观 / 听书」三页签，调参数时正文保持可见
* **进入阅读器优先读缓存**，弱网下不会长时间空转

### 听书

* 逐段朗读、自动跨章，段落高亮跟随；语速、音调可调
* 12 款在线音色：小臻、小瑜、晓晓（甜美女声）、云希（阳光青年）、云健（解说男声）、云夏（清亮少年）、晓伊（活力女声）、云扬（新闻播报）、晓北（东北味）、晓妮（陕西味）、晓曼（粤语女声）、云哲（台湾男声）
* 在线合成，结果本地缓存即开即读，断网自动回退系统语音
* **全屏听书页**：波形进度、上一段 / 暂停 / 下一段、正在朗读卡、音色切换与 15 / 30 / 60 分钟定时停止
* **安卓锁屏听书**：前台服务保活，锁屏与通知栏可直接上一段 / 暂停 / 下一段 / 停止

### 书架与记录

* 两种卡片样式：**长卡片 / 正方形卡片**，都带阅读进度条；列宽与间距自动计算，卡片间距与两侧留白完全相等，宽屏自动分列
* 六种排序（最近阅读、添加时间、书名、作者、进度、字数）× 正倒序
* 无封面时按书名稳定分配占位插画，不会每次刷新都换图
* 阅读记录：累计时长、连续天数、读完本数、最近 7 天柱状图，以及当天的书源可用情况
* 跨书书签总览，点一下跳回原文位置

### 全局联动

* **37 类操作**全部接入桌宠：翻章、书签、换排序、搜索、导入书源、换主题、朗读、清缓存……
* 每个动作都有对应的表情与台词；同一动作短时间内重复触发只涨成长值不刷屏

### 离线与其它

* 读过的章节自动落盘，断网无缝续读；支持整本下载、断点续传，随时暂停不白干
* 列表与封面本地缓存，冷启动秒开；缓存占用可视化，一键清理
* 搜索与发现页**实时出结果**：任一书源返回即刻上屏，不必等最慢的那个
* 安卓全程 edge-to-edge，顶部窄带就是状态栏本身那一行（原来显示时间 / 信号强度的位置）；窄带底色跟随阅读背景，不会割裂
* 实时公告：启动与运行中自动检查，新公告全屏直达（内容由 GitHub Pages 分发，改一处即全端生效）。同一条公告每人只弹一次，读过就不再打扰
* 自动更新：启动静默检查新版本，弹窗即更新公告；安卓一键安装；**Windows 交给独立更新器 `updater.exe` 后台包办**（多线路下载 → 解压校验 → 等主程序退出 → 整体换装 → 自动重启，全程不占 UI、写 `updater.log` 可查）；下载多线路回退并校验完整性
* 桌面端独立窗口，窄屏 / 宽屏自适应布局

## 下载

到 [Releases](https://github.com/leey1994/shuangyuebook/releases/latest) 页面下载：

| 平台 | 文件 | 体积 |
| --- | --- | --- |
| Android（64 位，推荐） | `ShuangYue-v1.0.3+9-arm64-v8a.apk` | 约 24 MB |
| Android（32 位老机型） | `ShuangYue-v1.0.3+9-armeabi-v7a.apk` | 约 22 MB |
| Windows | `ShuangYue-v1.0.3+9-windows-x64.zip`（内含 `novel_reader.exe` + 后台更新器 `updater.exe`）—— 解压即用，无需安装 | 约 18 MB |

> **为什么要按架构分开？** Flutter 每个 ABI 都要带一份自己的引擎（约 20 MB）。
> 三合一「通用包」会把 arm64 / armeabi-v7a / x86_64 三份都塞进去，体积直接到 ~68 MB。
> 所以官方只分发前两个：64 位手机（2016 年后的绝大多数机型）装 `arm64-v8a`，
> 提示"应用未安装"再换 `armeabi-v7a`；模拟器请按下方源码构建命令自己出 x86_64 包。
> 两者同包名同签名，可互相覆盖安装，数据不丢。

## 从源码构建

```bash
flutter pub get
flutter analyze
flutter test

# APP_VERSION 取自 pubspec.yaml 的 version，必须显式传 ——
# 「我的 → 关于」与自动更新都靠它判断有没有新版本。
# 安卓：--split-per-abi 出三个按架构分包（各 ~20 MB），不要用默认的通用包（~68 MB）。
flutter build apk --release --split-per-abi --dart-define=APP_VERSION=1.0.3
# 只要其中一个架构：
flutter build apk --release --target-platform android-arm64 --dart-define=APP_VERSION=1.0.3
flutter build windows --release --dart-define=APP_VERSION=1.0.3

# Windows 更新器（独立后台进程，打 Windows 包前必须先产出并放进 Release 目录）：
# 负责下载/解压/换装/重启，UI 进程只负责点火。
dart compile exe tool/updater.dart -o build/windows/x64/runner/Release/updater.exe
# 然后整目录打包成 ShuangYue-v1.0.3+9-windows-x64.zip（updater.exe 一并进包）。
```

桌面端的标题栏与桌宠活动区、顶部窄带这类只能肉眼确认的改动，可以用 `tool/shot.ps1` 启动桌面端并截图：

```powershell
powershell -ExecutionPolicy Bypass -File tool/shot.ps1 -Out build/shot.png -WaitMs 9000 -Dismiss
```

重新生成应用图标（各密度自适应图层 + 传统图标 + Windows ico）：

```powershell
powershell -ExecutionPolicy Bypass -File assets/icon/generate_icon.ps1
```
