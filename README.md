# 爽阅

Flutter 打造的双端（Android / Windows）小说阅读器——一处搜书、全网找书，离线能读，还能听。

静态主页：<https://leey1994.github.io/shuangyuebook/>

## 功能

### 多源聚合

* 内置顶点小说、速读谷、黄金屋、52书库、搬山人、神文小说、智能书库、素书卷、篱笆好文学、小原文学、全本小说网 11 个书源，全源同时搜索
* 搜索历史；发现页推荐 / 排行 / 书单聚合全部书源，一处浏览全网好书
* 换源续读：当前源缺章时一键换源，按章节名自动匹配阅读进度

### 阅读器

* 左右翻页 / 上下滚动双模式，滚动模式读到章末自动加载下一章
* 字号、行距可调，锦绣白 / 极光黑双主题
* 书签、进度条、目录跳转，阅读进度自动记忆（重开继续）

### 听书

* 逐段朗读、自动跨章，段落高亮跟随；语速、音调可调
* 12 款在线音色：小臻、小瑜、晓晓（甜美女声）、云希（阳光青年）、云健（解说男声）、云夏（清亮少年）、晓伊（活力女声）、云扬（新闻播报）、晓北（东北味）、晓妮（陕西味）、晓曼（粤语女声）、云哲（台湾男声）
* 在线合成，结果本地缓存即开即读，断网自动回退系统语音

### 离线与缓存

* 读过的章节自动落盘，断网无缝续读
* 列表与封面本地缓存，冷启动秒开；缓存占用可视化，一键清理

### 其他

* 自动更新：启动静默检查新版本，弹窗即更新公告；安卓一键安装，Windows 自动替换重启
* 书架与历史：收藏管理、进度与历史记录（可清空）、侧滑删除
* 桌面端独立窗口，窄屏 / 宽屏自适应布局
