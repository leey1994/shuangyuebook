## 1. 产品定位

**一句话**：一个没有服务器的多源聚合阅读器 —— 桌面上开着就能读，手机里揣着也能读，小墨陪着你读。

| 维度 | 定位 |
| --- | --- |
| 形态 | Android 手机端 + Windows 桌面端，同一套 Flutter 代码库 |
| 内容来源 | 纯客户端实时采集：**13 个内置书源**（全部手写原生适配、随包发布）+ 用户导入的「阅读 3.0」书源 |
| 架构成本 | **零服务器**：没有后端、没有数据库、没有账号体系，搜索与排行全部在客户端实时聚合 |
| 差异化 | ① 全源实时聚合（搜索/排行/推荐不再单源）② 桌宠小墨全程陪伴 ③ 双端像素级一致的体验 |

**设计原则**：
1. **内容优先** —— 界面为书让路，阅读器永远是第一优先级。
2. **零门槛** —— 打开即用，不注册、不登录、不喂数据。
3. **陪伴感** —— 小墨是产品的性格，不是装饰。
4. **懒到极致** —— 不建后端能做的事，绝不建后端。

## 2. 与现有爽阅工程的关系（能力继承清单）

品牌名沿用**爽阅**，但工程与视觉全新重做；现有爽阅工程的成熟能力整套搬入，不重复造轮子：

| 能力 | 现有工程现状 | 新工程做法 |
| --- | --- | --- |
| 桌宠小墨 | 4 形态养成、61 状态、300+ 台词、37 类操作联动、挖孔规避 | **整套搬入**，新增「我的」页陪伴面板（陪伴天数 / 下一形态进度条） |
| 书源引擎 | 「阅读 3.0」格式导入（JSON/文件/订阅链接）、批量启停 | 整套搬入，升级为**采集引擎**统一调度 |
| 内置书源 | 9 个手写适配（顶点、速读谷、黄金屋、52书库、神文、素书卷、篱笆好文学、小原、全本） | 原样搬入 + **新增 4 个原生适配**（鬼吹灯、抖音小说、伪速读谷、若雨中文，见 §4.1），共 13 个内置 |
| 阅读器 | 4 种翻页、8 项排版、6 种背景、页眉页脚、常亮、书签、缓存优先 | 搬入并重构为独立模块，新增目录内搜索 |
| 听书 | 12 款在线音色 + 系统语音回退、逐段高亮、跨章连续 | 搬入，新增定时停止（15/30/60 分钟）与锁屏听书（M4） |
| 本地书 | TXT/EPUB 导入、编码识别、自动分章、EPUB 封面插图 | 整套搬入，与在线书共用阅读体验 |
| 统计 | 时长、连续天数、读完本数、7 日柱状图 | 搬入 + **成就徽章系统**扩展至 14 枚 |
| 更新/公告/文件关联 | GitHub 分发、多线路更新、文件关联打开 TXT/EPUB/书源 | 整套搬入 |
| 双主题 | 锦绣白 / 极光黑 | 保留配色基因，升级为完整设计规范（见 §5） |

**哪些是新的**：
- **排行**从「发现页的一个 Tab」升级为**独立一级页面**（多榜单 × 多分类 × 全源聚合）。
- **搜索**重做为全屏页：实时上屏进度、来源筛选、同名书自动合并。
- **书详情**新增来源面板（当前源 / 可用源 / 一键换源续读）。
- **书架**新增分段控件（在线书架 / 本地书）与批量管理。
- 全新品牌视觉：墨绿主色 + 朱砂点缀（取自小墨额头的朱印）。

## 4. 功能设计（模块详设）

### 4.1 采集引擎（核心）

**数据流**：请求 → 并发调度 → 各源适配器解析 → 实时上屏 → 去重合并 → 缓存。

- **统一接口**（沿用爽阅 `NovelSource`）：`fetchHome / fetchRankTabs / fetchRank / search / fetchDetail / fetchChapter`，固化源与导入源完全同构。
- **并发策略**：搜索/排行/首页多源并行（建议并发 6，可在设置调整），任一源返回立即上屏，不等最慢的源；进度条显示「已从 N/M 个源返回」。
- **去重合并**：规范化（书名 + 作者），同一本书跨源合并为一条，列表中显示来源徽标；进入详情可查看全部可用源。
- **实时出结果**：输入 300ms 防抖后发起，结果**边到边显**（爽阅已有能力，保留）。
- **书源体检**：导入后自动批量检测，搜不出内容的源移除并说明原因；此后每日首次启动自动体检。
- **换源续读**：当前源缺章时一键换源，按章节名 + 章节序号自动匹配阅读进度。
- **限速与重试**：单站并发 ≤2、失败退避重试 3 次、统一 UA/referer；宁可报错让用户重试，不落半截正文（避免缓存污染）。

**内置书源清单（13 个，全部随包原生适配）**：9 个既有手写适配（顶点、速读谷、黄金屋、52书库、神文、素书卷、篱笆好文学、小原、全本）+ 4 个新增原生适配（鬼吹灯、抖音小说、伪速读谷、若雨中文）。

原 26 个候选站点的处置（V1.0.0 逐站实测定稿）：

| 结果 | 站点 | 原因 |
| --- | --- | --- |
| 转原生内置（4） | 鬼吹灯、抖音小说、伪速读谷、若雨中文 | 搜索 / 详情 / 目录 / 正文均可直连抓取，已逐站实测（含章内分页拼接） |
| 放弃（22） | 七猫聚合、起点、番茄小说(API)、kk笔趣阁、新龙小说网、智能书库、最终小说网、纸间、uu书库、书豪小说网、大文学无错、番茄小说(APP)、同人小说、书海阁、魔丸小说、得奇小说网、霹雳书屋、思路客、得奇小说、搬山人、74小说网、故事族 | 站点关停 / HTTP 403（Cloudflare）/ 搜索或正文走 JS 加密（签名 token、Base64 混淆目录，纯客户端无法复刻）/ 搜索恒空 |

- **落地方式**：全部为手写 Dart 适配器（`lib/sources/`），不走「阅读 3.0」引擎 —— 原 JSON 方案（325KB 资产 + 隐藏 WebView 引擎）实测大部分源在纯客户端环境采集不出内容（阅读的 JS 需 Rhino + java 桥，Android 专属且不可复刻），已废弃。
- **旧 JSON 资产**：`assets/sources/builtin_sources.json` 不再预置源，仅保留 `legacyBuiltinUrls` 清理清单 —— 存量安装启动时自动移除这 26 个旧导入源；原始 26 源定义留档于 `sources/legacy-26-sources.json`（测速数据见 `../sources/书源筛选报告.md`）。

### 4.2 首页

- 顶部：品牌行（小墨 + 爽阅）+ 全局搜索栏（点击进搜索页）。
- 轮播横幅：全源推荐交错抽取，5s 自动轮播，点击进详情。
- 分类快捷入口：玄幻/都市/仙侠/历史/科幻/悬疑/言情/游戏/二次元（映射各源分类表）。
- 热榜速览：聚合榜 TOP5，右上角「更多」跳排行页。
- 今日推荐：3 列卡片网格，每源等差抽取、跨源交错，点「换一批」重新随机子集。

### 4.3 排行（独立页）

- 榜单类型 × 分类二维筛选：热销 / 新书 / 完结 / 口碑 × 全部 + 9 分类。**口碑榜口径**：多源共同收录数排序 —— 被越多源收录的书排前（已确认）。
- 榜单数据 = 各书源榜单接口实时聚合，按各源榜内名次加权排序；条目显示：排名、封面、书名、作者、字数、状态、来源徽标、热度（有则显示）。
- TOP3 特写卡（大封面 + 名次角标），第 4 名起为紧凑列表，支持滚动分页。
- 页脚说明数据来源与刷新时间，可手动刷新。

### 4.4 搜索

- 进入先展示：搜索历史（≤10 条，可清空）+ 热门搜索词（来自各源热词聚合）。
- 结果页：实时上屏进度条 + 来源筛选 chips（全部/单源勾选）+ 结果列表（书名关键词高亮、作者、标签、字数状态、来源徽标）。
- 同名书自动合并，右侧显示「N 个来源」；点击进详情。
- 空结果给出引导：换关键词 / 去书源管理导入更多源。
- 阅读器内搜索：目录搜索（章名定位）+ 正文搜索（当前已缓存章节内匹配）。

### 4.5 书架

- 分段：**在线书架** / **本地书**；顶部显示数量。
- 视图切换：方格卡片（3 列）/ 长卡片（列表），均带阅读进度条与百分比。
- 排序：最近阅读 / 添加时间 / 书名 / 作者 / 进度 / 字数，各支持正倒序。
- 长按进入多选：批量删除、置顶；无封面时按书名稳定分配占位插画（同一本书不换图）。
- 网格尾部固定「+ 导入本地书」虚线卡（入口可视化，不用翻设置）。

### 4.6 书籍详情

- 头部：封面 + 书名 + 作者 + 标签（分类 · 连载/完结 · 字数 · 最新章节）。
- 热度行：在读数（来自榜单接口，聚合展示）；无数据则不显示，不造假。
- **来源面板**：当前来源（如「顶点小说」）+ 可用源数量 + 一键换源；换源后按章节名自动对齐进度。
- 操作区：加入书架（主按钮）+ 听书（圆形次按钮）+ 分享（生成文字卡片）。
- 简介（3 行折叠）、目录（正/倒序、跳转、章内搜索）、底部固定操作条（目录 / 听书 / 加入书架）。
- 已在书架的书：主按钮变「继续阅读」并显示进度。

### 4.7 阅读器

- 翻页：滑动 / 覆盖（逐行对照阅读 3.0 手感）/ 淡入 / 滚动，四种任选；翻页吸附固定速率收敛。
- 排版：字号、行距、字距、左右边距、上下留白、首行缩进，实时预览（面板下正文保持可见）。
- 外观：6 种背景（纸白/米黄/护眼绿/浅灰/夜间/纯黑）、页眉（章节名）与页脚（时间/页码/电量）分别开关。
- 阅读体验：常亮、书签、进度条拖动、章末继续拖动直接进下一章、目录跳转、进度自动记忆。
- 缓存优先：进入阅读器先读本地缓存，弱网不空转；后台预取下一章。
- 顶部保留小墨窄带（不打扰正文，随阅读时长成长）。

### 4.8 听书

- 逐段朗读、自动跨章、段落高亮跟随；语速 0.5x–3.0x、音调可调。
- 12 款在线音色（小臻/小瑜/晓晓/云希/云健/云夏/晓伊/云扬/晓北/晓妮/晓曼/云哲），结果本地缓存即开即读。
- 断网自动回退系统语音（Android TTS / Windows SAPI）。
- 新增：定时停止 15/30/60 分钟；**锁屏听书**（Android 前台服务 + 通知栏控制播放/暂停/切章，M4 落位）。

### 4.9 本地书

- 导入 TXT / EPUB：内置文件浏览器多选 + 常见目录批量扫描；Android 11+ 走「所有文件访问」权限门。
- TXT：UTF-8/UTF-16/GBK 自动识别，按章节标题模式自动分章；EPUB2/3 双目录解析、抽取封面与插图。
- 本地书与在线书共用阅读、缓存、书签、统计；文件关联：文件管理器直接「用爽阅打开」TXT/EPUB/书源 JSON。

### 4.10 桌宠小墨

- 成长：墨滴 → 纸兽 → 墨狐 → 书灵（长期陪伴节奏，第一阶约两周）。
- 形态统一：水滴头、页角耳、额头朱印贯穿四形态。
- 行为：呼吸/眨眼/自主玩耍（跳、翻身、伸懒腰、打哈欠）；阅读时钉在顶部预留带，其它界面自由溜达，行走时按方向翻面。
- 屏幕挖孔规避（设置里选挖孔位置），凑近摄像头会探头。
- 场景台词：按时段问候、久别重逢、久坐护眼、深夜劝睡，61 状态 × 300+ 台词随机不重复。
- 全局联动：翻章、书签、换排序、搜索、导源、换主题等操作触发对应表情与台词（同动作短时重复只涨成长值不刷屏）。
- 「我的」页陪伴面板：当前形态、成长值进度、陪伴天数；可在设置一键关闭，不影响任何功能。

### 4.11 统计与成就

- 统计卡：累计时长、连续天数、读完本数；最近 7 天柱状图；当天书源可用情况汇总。
- 成就徽章 14 枚：首读达成、连续 7 天、夜读诗人、听书达人、换源大师（「我的」页预览行）+ 连续天数 3/14/30 天、累计时长 10/50/100 小时、读完 1/10/50 本；点亮时小墨报喜 +10 成长值。「我的」页展示前 5 枚 + 「查看全部 14 枚」。

### 4.12 设置

- 主题（锦绣白/极光黑）、桌宠（开关/挖孔位置）、听书（默认音色/语速）、阅读（默认翻页/排版）。
- 书源管理：内置 35 源 + 导入源列表，批量启停、删除、导出、体检结果。
- 缓存：占用可视化（章节/封面/音频分类）、一键清理。
- 更新与公告、开源许可、关于（版本号来自构建参数）。
- 采集并发数、只读模式（仅读缓存）等进阶项。

### 4.13 离线与离线缓存

- 读过的章节自动落盘，断网无缝续读；整本下载（断点续传、随时暂停）。
- 列表与封面本地磁盘缓存（冷启动秒开）；章节缓存 LRU 上限可配（默认 500MB）。

### 4.14 更新 / 公告 / 文件关联

- 启动静默检查新版：Android 一键安装，Windows 自动替换重启；多线路下载回退 + 整包校验。
- 实时公告：启动与运行中每 10 分钟检查，新公告全屏直达，同一公告只弹一次。
- 文件关联：TXT/EPUB → 导入并进阅读器；书源 JSON → 导入书源。

### 5.2 字体

- UI 字体：系统默认（Android：思源黑体/鸿蒙；Windows：微软雅黑）。
- 正文（阅读器）：衬线优先（宋体系），可切换黑体。
- 字号规范：页面标题 20/700，区块标题 15/700，正文 14，次要 12，徽标 10。
- 阅读正文默认 17px、行距 1.9、首行缩进 2em（可调）。

### 5.3 形状与间距

- 圆角：卡片 16、按钮 12、搜索框/胶囊 999、封面 8~10、弹层顶部 20。
- 间距：页面左右留白 16，卡片间距 12，区块间距 20。
- 阴影：卡片极轻（y2 blur8 alpha 4%），仅悬浮元素加重。
- 网格：安卓 3 列书架卡，Windows 主区自适应 4~6 列。

### 5.4 双端适配

- 断点 720 逻辑宽：`<720` 底部 4 Tab；`≥720` 左侧 NavigationRail（可展开）+ 多栏内容 + 右侧辅助栏（继续阅读/榜单/小墨）。
- Windows：自绘标题栏（可拖动/缩放），窄窗自动降级为移动布局。

### 5.5 动效

- 时长 150–250ms，标准缓动；翻页动画独立（见 4.7）。
- 小墨动作不阻塞任何界面操作；列表加载用骨架屏而非转圈。

- **模块映射**（现有爽阅工程文件 → 新工程模块）：

| 新工程模块 | 复用来源 |

| 网络与解析 | `lib/net.dart`、`lib/dom.dart`、`lib/feed_cache.dart` |
| 阅读器 | `lib/screens/reader_screen.dart`、`lib/paginate.dart`、`lib/ui/reader/*` |

| 本地书 | `lib/local/*` |
| 小墨 | `lib/pet/*`、`lib/ui/pet_top_band.dart` |
| 统计 | `lib/data/stats_store.dart` |
| 壳与平台 | `lib/main.dart`、`lib/title_bar.dart`、`lib/platform/*`、`lib/update_check.dart`、`lib/announcement.dart` |
| 存储 | `lib/store.dart`、`lib/models.dart` |

- **建议目录**：

```
shuangyue/
  lib/
    core/      net / dom / cache / format
    collect/   引擎 + adapters（13 个原生内置源）+ legado 导入
    reader/    分页排版 + 阅读器 + 翻页动画
    tts/      听书
    local/    txt / epub
    pet/      小墨
```

- **缓存策略**：内存 LRU（列表/封面）→ 磁盘章节库（按源+书+章哈希，LRU 可配）→ 音频缓存；冷启动只读磁盘不触网。

## 8. 风险与合规

| 风险 | 对策 |
| --- | --- |
| 目标站改版导致采集失效 | 已有「书源体检 + 逐条说明 + 换源」机制；适配器集中在一处，修复成本低 |
| 反爬（限速/封 IP/令牌墙） | 单站并发 ≤2、重试退避、统一 UA；令牌墙站点走内置隐藏 WebView 引擎（爽阅已解决速读谷同类问题） |
| 主站全部失效的风险 | 支持导入「阅读 3.0」书源，用户可自救；内置 13 个源互为备份，单站失效自动换源兜底 |
| 版权与合规 | 与爽阅同策略：不捆绑、不分发、不存储受版权保护内容，仅提供采集索引与阅读工具；离线缓存仅在用户设备本地；应用内明确版权声明，仅供个人学习研究 |
| 商店上架 | 若需上架，首发以官网/侧载分发为主；合规版可只保留「用户自行导入书源」通道 |
