安卓端 Android · 逻辑基准 390 × 844 · 底部 4 Tab

顶部状态栏一行由小墨驻守（爽阅基因，挖孔自动避让）；搜索全局可达；首页 / 排行 / 书架 / 我的四条根导航。

Windows 端 桌面 · 宽屏 ≥ 720 逻辑宽 · 侧栏 + 多栏

自绘标题栏（爽阅同款，可拖动 / 缩放）；左侧 NavigationRail 常驻；宽屏主区多栏，小墨从顶部链路走进侧栏卡片。

说明
  • 逻辑基准：安卓 390 × 844；桌面断点 720 —— 窄窗自动降级为移动布局，Windows 自绘标题栏可拖动 / 缩放。
  • 色彩、字号、圆角均取自《设计方案》§5 设计规范；6 档阅读背景与爽阅完全一致（纸白 / 米黄 / 护眼绿 / 浅灰 / 夜间 / 纯黑）。
  • 小墨为 SVG 复刻示意（水滴头 / 页角耳 / 额头朱印），正式实现直接启用爽阅现有桌宠系统（四形态养成）。
  • 内置书源 13 个，全部为手写 Dart 原生适配、随包内置：搜索 / 详情 / 目录 / 正文全链路直连站点，不依赖任何外部脚本。
  • 榜单、热度、章节名为示意占位；真实数据以各书源返回为准，无数据字段一律隐藏，不造假。
  • 本文件为高保真静态原型，交互仅为示意；动效与翻页手感以 M3 里程碑真机验收为准。
