它是什么

一个双端小说阅读器。内置书源开箱可读，也能导入「阅读 3.0」格式书源；TXT / EPUB 本地书和在线书共用同一套阅读体验，断网也能接着读。

顶部住着一只会陪你长大的小兽 —— 墨滴、纸兽、墨狐、书灵，看着你做的每一件事变化。

功能

书源

内置 9 个固化书源；支持导入书源，可批量启停、删除与导出。导入后自动体检，失效的直接移除并说明原因。

阅读

四种翻页、行距字距主题、护眼背景、离线缓存、整本下载与断点续传，换源续读按章节名自动对齐进度。

本地书

TXT 与 EPUB 都能导入，和在线书走同一条阅读、缓存、书签通路。

听书

在线音色朗读，可调语速，随时切回阅读。

桌宠养成

阅读时钉在顶部不打扰正文，其余界面整屏自由溜达，会绕开屏幕挖孔。61 种触发状态、300 多条台词。

双端

Android 与 Windows 共用一套代码，窄屏宽屏自适应，桌面端独立窗口。

内置书源

第三方站点经常改版或关闭。失效的源会在「书源管理」里被体检标出，可随时停用或删除；也可以导入自己的书源来接替。
