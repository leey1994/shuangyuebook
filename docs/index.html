v1.1.0 新增

这一版把「书源」从固定清单变成了可扩展的引擎。

本次更新 v1.1.0

  • 书源引擎：支持导入「阅读 3.0」格式书源，粘贴 / 文件 / 订阅链接三种导入方式，可批量启停与导出。
  • 书源体检：导入后自动批量检测，搜不出内容的书源直接移除并说明原因；此后每天首次启动自动体检一次。
  • 本地书：支持导入 TXT 与 EPUB，自动识别编码、分章、抽取封面与插图，可按目录批量扫描。
  • 阅读器升级：新增滑动 / 覆盖 / 淡入 / 滚动四种翻页方式，字距、页边距、首行缩进、正文字体可调，页眉页脚可分别开关。
  • 阅读记录：累计时长、连续天数、最近 7 天柱状图，以及当天的书源可用情况一览。
  • 搜索与推荐实时出结果：任一书源返回即刻上屏，进度钉在搜索框正下方，不必等最慢的那个。
  • 书架增强：网格 / 小图 / 列表三种视图，六种排序方式，无封面时按书名分配占位插画。
  • 文件关联：文件管理器里直接用爽阅打开 TXT / EPUB / 书源 JSON。

功能亮点

在线书与本地书共用同一套阅读、缓存、书签与统计。
◈

书源引擎

内置 10 个固化书源，另可导入「阅读 3.0」格式书源扩展。两种书源在搜索、发现、书架、换源里完全同构，可以混用。

✓

书源体检

导入后自动批量验活，失效书源直接移除并说明原因；每天首次启动自动体检，结果汇总在阅读记录页。

▤

本地书

导入 TXT / EPUB：自动识别 UTF-8、UTF-16、GBK 编码，自动分章，抽取封面与书内插图，支持按目录批量扫描。

⇄

四种翻页

滑动 / 覆盖 / 淡入 / 滚动。覆盖模式逐行对照「阅读 3.0」的手感实现，翻页吸附按固定速率收敛，不会拖尾。

Aa

排版与背景

字号、行距、字距、左右边距、上下留白、首行缩进、正文字体可调；6 种阅读背景，页眉页脚分别开关。

♪

听书

逐段朗读、自动跨章、段落高亮跟随。12 款在线音色在线合成并缓存到本地，断网自动回退系统语音。

⇩

离线缓存

读过的章节自动落盘，无网络时离线续读；支持整本下载、断点续传，可随时暂停不白干。

◷

阅读记录

累计时长、连续阅读天数、读完本数、最近 7 天柱状图，以及当天的书源可用情况。

↻

自动更新

启动静默检查新版本，弹窗公告即 Release 说明；安卓一键安装，Windows 自动替换重启，多线路回退不怕网络抽风。

▣

书架与换源

三种视图、六种排序、无封面自动分配插画；换源保留阅读进度，按章节标题自动对齐。

☰

实时公告

启动与运行中自动检查公告，发现即全屏直达；发布只需改一处文件并推送。

▣

双端自适应

同一套代码覆盖 Android 与 Windows 桌面端，宽窄屏自动切换导航形态与文字缩放。

技术说明

◈

书源架构

所有书源（固化与导入）实现同一个接口，因此搜索、发现、书架、阅读器、换源、离线缓存无需区分来源。

♪

Windows 听书

自研 SAPI5 插件（vendored 于 third_party/flutter_tts）：经典 Desktop 音色 + OneCore 音色枚举，规避 WinRT 引擎崩溃与低完整性静音。

▤

本地书解析

EPUB 走 OPF / NCX / nav 双目录解析并抽取插图；TXT 按字节特征探测 UTF-8 / UTF-16 / GBK，再按章节标题模式切分。
