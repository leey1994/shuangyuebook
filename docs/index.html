v1.2.1 桌宠养成 · 联动 · 瘦身 2026-10-10
新增
  • NEW桌宠「小墨」：顶部常驻一只书页精灵，四种形态随阅读时长自然成长，全程是同一个角色；会自己散步、自己玩。
  • NEW按场景说话：61 种触发状态、300 多条台词随机取用，半透明气泡显示在身旁；深夜劝睡，不催更不施压。
  • NEW全局联动：37 类操作全部接入桌宠，每个动作都有对应的表情与台词。
  • NEW书架两种卡片：简化为长卡片与正方形卡片，都带阅读进度条；列宽与间距自动计算，横向正好铺满。
  • NEW在线正文字体：「霞鹜文楷」改为按需下载，不再随安装包分发；下载一次后长期保留、可离线。
改进
  • 安装包体积 30.2 MB → 22.4 MB（-26%）。
  • 进入阅读器优先读缓存，弱网下不再长时间空转。
  • 滑到章节末尾继续拖动即可直接进入下一章。
  • 读到最后一章末尾会记一次「读完一本」。
修复
  • Windows 最小化 / 最大化 / 关闭按钮不显示。
  • 安卓顶部多占了一条空白带 —— 现在窄带就是状态栏本身，顶部只占一层。
  • 宽屏下长卡片铺满整行，进度条被拉成长线。
  • 隐藏状态栏时正文顶部留白不足，文字贴边。
  • 滑动翻页在章节末尾卡住，翻不到下一章。
  • 启动图标存在叠影，边缘发虚。
  • 清空搜索后仍在进行的那轮搜索会冒出旧结果。
升级提示
  • 桌宠可在「设置 → 桌宠」关闭，不影响任何功能。
  • 「霞鹜文楷」首次使用需联网下载约 13 MB；不下载则继续使用系统字体。
  • 本版本不新增任何权限申请。

/ capabilities

功能亮点

在线书与本地书共用同一套阅读、缓存、书签与统计。

◈

书源引擎

内置 10 个固化书源，另可导入「阅读 3.0」格式书源扩展。两种书源在搜索、发现、书架、换源里完全同构，可以混用。

✓

书源体检

导入后自动批量验活，失效书源直接移除并说明原因；每天首次启动自动体检，结果汇总在阅读记录页。

▤

本地书

导入 TXT / EPUB：自动识别 UTF-8、UTF-16、GBK 编码，自动分章，抽取封面与书内插图，支持按目录批量扫描。

⇄

四种翻页

滑动 / 覆盖 / 淡入 / 滚动。覆盖模式逐行对照「阅读 3.0」的手感实现，翻页吸附按固定速率收敛，不会拖尾。

Aa

排版与背景

字号、行距、字距、左右边距、上下留白、首行缩进、正文字体可调；6 种阅读背景，页眉页脚分别开关。

♪

听书

逐段朗读、自动跨章、段落高亮跟随。12 款在线音色在线合成并缓存到本地，断网自动回退系统语音。

⇩

离线缓存

读过的章节自动落盘，无网络时离线续读；支持整本下载、断点续传，可随时暂停不白干。

◷

阅读记录

累计时长、连续阅读天数、读完本数、最近 7 天柱状图，以及当天的书源可用情况。

◑

养成桌宠

阅读时长直接换算成长值，配合搜索与抚摸一起推动进化；四个阶段、四种情绪，会在你久坐、深夜、久别时主动开口。

↻

自动更新

启动静默检查新版本，弹窗公告即 Release 说明；安卓一键安装，Windows 自动替换重启，多线路回退不怕网络抽风。

▣

书架与换源

长卡片 / 正方形卡片两种样式带进度条，两种排序方向；换源保留阅读进度，按章节标题自动对齐。

▤

双端自适应

同一套代码覆盖 Android 与 Windows 桌面端，宽窄屏自动切换导航形态与文字缩放。
