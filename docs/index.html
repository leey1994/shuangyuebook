功能亮点

多源聚合

内置 4 个书源，单源或全源搜索，一处搜书全网找；支持换源续读，章节匹配当前进度。

阅读器

左右翻页与上下滚动双模式，滚动模式读到章末自动续载；书签、进度条、字号行距、双主题。

听书 TTS

系统语音合成逐段朗读、自动跨章、段落高亮跟随；语速 / 音调可调，多声色可选，内置「小智（温柔）」预设。

离线缓存

读过的章节自动落盘，无网络时自动离线阅读；发现页列表与封面本地缓存，冷启动秒开。

自动更新

启动静默检查 GitHub 新版本，弹窗公告即 Release 说明；安卓一键安装，Windows 自动替换重启。

书架与历史

加入 / 移出书架、阅读进度与历史（可清空）、侧滑删除、长按进详情。

技术说明

架构

单一 Flutter 代码库覆盖 Android / Windows；书源为可扩展抽象基类，新增书源只需实现解析逻辑。

Windows 听书

自研 SAPI5 插件（vendor 于仓库 third_party/flutter_tts）：经典 Desktop 音色 + OneCore 音色注册表枚举，规避 WinRT 引擎崩溃与低完整性静音问题。

Android 听书

系统 TTS 引擎（Google / 厂商语音均可），多声色列表直接来自引擎；已在 Manifest 声明 TTS 包可见性，Android 11+ 正常发声。
