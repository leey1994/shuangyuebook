它是什么

一个双端小说阅读器。内置书源开箱可读，也能导入「阅读 3.0」格式书源；TXT / EPUB 本地书和在线书共用同一套阅读体验，断网也能接着读。

顶部住着一只会陪你长大的小兽 —— 墨滴、纸兽、墨狐、书灵，看着你做的每一件事变化。

功能

书源

内置 13 个书源（全部手写原生适配、随包内置）：搜索、详情、目录、正文全链路直连各站点；也支持导入「阅读 3.0」格式书源，可批量启停、删除与导出。导入后自动体检，失效的直接移除并说明原因。

排行发现

热榜 / 好评榜 / 口碑榜 / 完结榜，跨源聚合去重合并 — 口碑榜按多源共同收录排序，每个名次都真实来自书源的榜单，不造假。

阅读

四种翻页、行距字距主题、六档护眼背景、离线缓存、整本下载与断点续传；换源续读按章节名自动对齐进度。

本地书

TXT 与 EPUB 都能导入，和在线书走同一条阅读、缓存、书签通路。

听书

12 款在线音色，段落高亮跟随、自动跨章、定时停止；安卓支持锁屏与通知栏控制，切回阅读随时继续。

桌宠养成

阅读时钉在顶部不打扰正文，其余界面整屏自由溜达，会绕开屏幕挖孔。61 种触发状态、300 多条台词。

双端

Android 与 Windows 共用一套代码，窄屏宽屏自适应：手机四标签，桌面左侧栏 + 宽屏多列。

双端渲染

一套 Flutter 代码，两副面孔：手机底部四 Tab（首页 / 排行 / 书架 / 我的），桌面自绘标题栏 + 侧栏宽屏多栏。下图为同一版本的设计渲染。

内置书源

内置 13 个书源，全部随包内置、开箱即用：搜索 / 详情 / 目录 / 正文全链路直连站点，解析在本地完成，不依赖任何外部脚本。第三方站点经常改版或关闭，失效的源会在「书源管理」里被体检标出；也可以导入自己的书源来接替。
