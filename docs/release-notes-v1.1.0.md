# v1.1.0 更新说明

这一版把「书源」从一份固定清单，变成了一个可以自己长大的引擎。

## 新增

### 书源引擎

- 支持导入「阅读 3.0」格式书源，粘贴 JSON、选择文件、订阅链接三种导入方式
- 书源可批量启用、停用、删除，支持导出与订阅更新
- 内置固化书源与导入书源完全同构：搜索、发现、书架、阅读器、换源、离线缓存都不区分来源，可以随意混用
- 新增 4 个公共版权内容书源作为开箱即用的默认选项

### 书源体检

- 书源导入后自动批量检测，搜不出内容的书源直接移除，并逐条列出「删了谁、为什么」
- 每天首次启动自动体检一次，结果写入本地档案
- 阅读记录页新增「今日书源检测」卡片，一眼看出今天多少可用、哪些失效、各自什么原因
- 书源管理页新增手动检测按钮，可随时复检

### 本地书

- 支持导入 TXT 与 EPUB，内置文件浏览器多选，也支持按常见目录批量扫描
- TXT 自动识别 UTF-8 / UTF-16 / GBK 编码，并按章节标题模式自动分章
- EPUB 支持 EPUB2 与 EPUB3 双目录解析，自动抽取封面与书内插图
- 本地书与在线书共用同一套阅读、缓存、书签与统计
- 新增文件关联：文件管理器里可直接用爽阅打开 TXT / EPUB / 书源 JSON

### 阅读器升级

- 新增四种翻页方式：滑动、覆盖、淡入、滚动
- 覆盖模式逐行对照「阅读 3.0」的手感实现，页面跟随手指推开并带前缘投影
- 翻页吸附改为固定速率收敛，不再出现「停一下才归位」的拖尾
- 排版新增：字距、左右边距、上下留白、首行缩进、正文字体切换
- 新增 6 种阅读背景，页眉与页脚可分别开关
- 新增内置正文字体「霞鹜文楷」
- 阅读时保持屏幕常亮；页脚实时显示时间、页码与电量
- 设置面板改为「排版 / 外观 / 听书」三页签，调参数时正文保持可见

### 书架与记录

- 书架新增三种视图（网格 / 小图 / 列表）与六种排序方式，含正倒序切换
- 无封面时按书名稳定分配占位插画，不会每次刷新都换图
- 新增阅读记录页：累计时长、连续阅读天数、读完本数、最近 7 天柱状图
- 新增跨书书签总览，点一下跳回原文位置

## 改进

- 搜索与发现页改为实时出结果：任一书源返回即刻上屏，不必等最慢的那个
- 搜索进度条钉在输入框正下方，滚动时始终可见
- 清空搜索框会连同结果与进度一并清除，并作废仍在进行的那轮搜索
- 发现页推荐融合导入书源的内容，每个导入书源最多贡献 5 本，避免刷屏
- 离线缓存整本下载改为逐章落盘，支持断点续传与随时暂停
- 自动更新下载增加多线路回退与完整性校验，镜像返回错误页时不会装到坏包

## 移除

- 下线内置书源「智能书库」（www.zzbook.net）：站点长期不可用，已从固化清单中移除，其余 10 个内置书源不受影响

## 修复

- 换源后阅读进度对齐异常
- 调整字号时正文偶发不重排
- 滚动模式跨章连载时底部留白残留
- 更新安装流程在部分设备上静默失败

## 升级提示

- 首次启动会在首页询问「所有文件访问」权限，用于导入本地书。不授权也能正常使用在线书
- 书源导入后会进行一次批量检测，属于正常流程，耗时取决于书源数量与网络
