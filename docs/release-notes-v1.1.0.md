## 用户向说明

### 新增

- **数据备份 / 恢复**：「我的 → 数据备份」。书架、阅读进度、书签、偏好、书源、书源变量、阅读统计打包成一个 JSON，放在 `Documents/爽阅备份`（卸载重装后仍在）。恢复时整表替换偏好、书源按地址合并。
- **替换净化**：「我的 → 阅读 → 替换净化」。自定义跨书源生效的正文替换规则，去广告行、去乱码一次配好所有书源通用；支持正则 / 纯文本、开关与示例预览。规则不写入章节缓存，改完回阅读器立即生效。
- **书架分组**：书架排序 chips 末尾多了「分组」，可按分组筛选、新建分组；批量管理里可把选中的书一次性移入分组。删分组只把书退回「未分组」，不会删书。
- **书源登录**：书源详情页新增「登录 / Cookie」。Android 直接开网页登录，登录后一键收下 Cookie；Windows 等没有 WebView 的平台可手动粘贴 Cookie，清除登录态也在同一处。
- **书源调试器**：书源详情页新增「调试」。输入关键词或书页地址，分别跑搜索 / 详情目录 / 正文，直接看到解析结果与耗时，写规则时不用再黑盒猜。
- **阅读 2.0 书源明确拒收**：导入 2.0 格式时会提示「拒收 N 个」，不再悄悄变成搜不到书的坏源。
- **EPUB 插图**：书里的插图现在会真正显示（此前只有「［插图］」占位）。图片按页高固定块排版，不会撑破页面；听书会自动跳过图片段。
- **用 AI 生成书源**：书源管理 →「+」→「用 AI 生成书源」。填小说站地址和自己的模型接口（OpenAI 兼容，型号自动获取、拉不到可手填），App 抓页面、生成规则、再用本机解析引擎实测搜索/目录/正文，通过才入库。新增「先浏览一遍」：在内置浏览里把一本书从搜索读到正文走完，每一步的页面结构直接喂给模型，命中率与速度都大幅提升（桌面端粘贴各页地址同效）。
- **听书全面升级**：退出阅读器朗读不再中断（后台播放），主界面底部出现悬浮播放条，上一章 / 暂停 / 下一章 / 关闭就地可用；通知栏按钮升级为上一章 / 下一章 / 暂停；朗读改为逐句断句，长句自动分摊，暂停后从本句续读。

### 优化

- 搜索、排行结果先到先上屏且不再整表重算，源多时更跟手；首页 / 排行 / 搜索的磁盘缓存改为异步读写，并自动清理 24 小时前与超出数量上限的缓存文件。
- 本地 TXT / EPUB 的解析搬到后台，导入大文件不再卡首帧；正文按章现切，不再整本常驻两份内存。
- 阅读器长章节分批补排时只刷新页脚页数，不再每几毫秒重建整页；切换章节不再累积残留的段落 key。
- 打开章节不再反复重写整本目录（千章目录约 150 KB）。
