## 爽阅 V1.0.1

**书源体验大修：全量实测驱动，搜索可用源 38 → 107。**（覆盖安装即可升级，书架、书源、进度、缓存全部保留）

### 书源引擎全量兼容修复（651 源实测）

* 以 651 条合集书源（7 大合集去重）做真实网络全量探针，逐项对齐「阅读 3.0」解析规则：模板表达式、XPath / CSS（排除 / 切片）、JSONPath 过滤、`@put` / `@get` 变量、`@js:` 后缀降级、相对链接补全、目录 / 正文翻页与净化、发现页入口顺序
* 新增「从网络获取并测试」：内置公开书源合集地址（也可填任意订阅链接），一键「获取 → 全链路测试 → 导入可用源」——测试逐条跑搜索 / 目录 / 正文三段，坏源不进门

### 导入书源，少填多选

* 「从文件导入」改为**内置文件浏览器**：手机上默认落在 Download 目录，点选即导入 —— 不用再手输完整路径（桌面端同样适用，另留「手输路径」兜底）
* 导入后的自动体检改为**先报告、后确认**：列出没通过的源与原因，删不删由你拍板 —— 网络抖一下也不会误伤刚导入的好源

### 首页 · 搜索 · 详情

* 首页全源聚合**实时响应书源变化**：导入 / 启用 / 删除后，「N 源聚合」与推荐流立即刷新
* 搜索页来源筛选改为**两行铺开 + 横向滑动**：书源再多也一眼看得全
* 详情页**加载失败自动换源**：原来源打不开（如站点已删书返回 404）时，自动在其它源里搜同名书并切换过去，全部失败才显示错误页
