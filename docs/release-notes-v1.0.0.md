## 爽阅 V1.0.0

**全新起点：爽快阅读，想看就看。**（从 v0.0.4 直接升级，书架、书源、进度、缓存全部保留）

### 内置书源重构：13 个，全部原生采集

- 内置书源从此全部为手写 Dart 原生适配：搜索 / 详情 / 目录 / 正文全链路直连站点，解析在本地完成，不经过任何脚本引擎，判定更准、速度更快
- 新增 4 个原生源：**鬼吹灯、抖音小说、伪速读谷、若雨中文**（章内分页自动拼接）
- 原 26 个随包导入源中其余站点：或已关站，或走 JS 加密接口 / Cloudflare 拦截（纯客户端无法复刻其脚本），或目录结构混淆 —— 已一并移除，不再假装可用
- 升级启动后自动清掉这 26 个旧导入源；你自行导入的书源不受影响，导入区仍可用「阅读 3.0」格式补充替代站点（订阅链接 / 粘贴 JSON / 选择文件）

### 设置并入「我的」

- 「设置」独立页面移除，全部设置项并入「我的」：**书源与内容 / 阅读 / 书架与记录 / 桌宠 / 离线缓存 / 关于** 六个卡片区
- 沿用「我的」原有卡片行风格：滑块、开关、下拉、阅读背景色点、检查更新、清缓存（含桌宠联动）
- 首页 ⋯ 菜单与「我的」页头的齿轮入口一并移除 —— 少一个入口，多一分顺手

### 稳定性

- Windows 端数据目录从系统临时目录迁到应用数据目录（磁盘清理不再丢书源与统计），首次启动自动搬迁旧文件

### 下载

到 [Releases](https://github.com/leey1994/shuangyuebook/releases/latest) 页面下载：

| 平台 | 文件 |
| --- | --- |
| Android | `novel_reader_android.apk` |
| Windows | `novel_reader_windows_x64.zip`（内含 `novel_reader.exe`）—— 解压即用，无需安装 |
| iOS | 工程已就绪，需自行在 macOS + Xcode 上签名构建 |

已装 v0.0.4 的用户在应用内点「检查更新」即可一键升级。
