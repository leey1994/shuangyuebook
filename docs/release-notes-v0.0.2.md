## 爽阅 v0.0.2

**体验修复版。**

### 修复

- **目录定位当前章节**：阅读中打开目录，平滑滚动定位到当前在读章节（先按实测行高算目标位，落点再对当前章条目做居中精修），不再每次从第一章开始排列
- **切章竞态**：快速连点目录 / 拖动进度条时，旧章节的网络结果迟到会把正文盖到新章节上——现在按加载代数丢弃过期结果，进度恢复回调同样受守卫
- **GBK 正文乱码**：网络层「GBK 兜底」原先实际走的是 latin1，GBK 站点正文全是乱码；改用真 GBK 解码（fast_gbk，与书源引擎同一条解码链），失败再退回宽松 UTF-8
- **详情页闪退**：「加载更多目录」请求返回时若已退出详情页，会对已销毁的 State 调 setState——补上挂载检查
