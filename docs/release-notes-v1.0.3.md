## 爽阅 V1.0.3

**书源解析更"认规矩"、翻页更跟手、缓存更省地方。**（覆盖安装即可升级，书架、书源、进度、缓存、听书音频全部保留）

这版没有大改界面，改的是"看不见但天天用得上"的部分：导入的「阅读 3.0」书源能用得更多、进章更快、翻页不再先卡一下，安卓安装包也回到正常体积。

### 书源 · 解析兼容性

* **XPath 系书源**：`./`、`../`、`.//` 这类相对写法现在都认（以前整条规则直接返回空），`and` / `or` / `not()` / `starts-with()` / `string()` 这些常见判断也补齐了
* **宁可返回空，也不返回错的东西**：遇到还不支持的复杂条件（比如 `substring()`），这条规则按"取不到"处理，不再把整页链接都当成结果塞给你
* **目录用 XPath、字段用 CSS 写法的源**：每一条只在自己的那条目录里取值，不再把"全站所有链接"拼进来 —— 这类源以前症状是**目录只剩 1 章**，日志里还看不出问题
* **大写前缀**：`@Json:`、`@XPath:`、`@CSS:` 这些大写写法与「阅读 3.0」一致，不再静默失效
* **`##` 替换链不再提前吃掉换行**：多行正文、分段书名在替换前保持原样，替换规则命中得更准

### 速度 · 翻页与加载

* **进章首屏立刻出字**：正文分页改成"先排第一屏、剩下的逐帧补算"，长章节不再先白屏卡 200\~300 毫秒
* **规则解析缓存**：同一条规则只解析一次（`##` 替换链快约 2.7 倍，整页解析快约 30%），搜索、目录、正文都受益
* **JS 书源省时**：同样的脚本配同样的输入直接复用上次结果，不再重复编译执行（有网络/时间/随机/写变量行为的脚本仍每次实跑，不会拿到旧值）
* **发现页 / 搜索更快**：请求头与发现页分类 1 分钟内复用，翻来翻去不再对每个源重算一遍
* **空结果不再被缓存**：搜不到的书不会"卡"在缓存里，换个关键词再来就能重新问源

### 存储 · 更省、更稳

* **章节缓存一章一文件**：进章只读一个小文件，不再每次读写整本书的大文件；旧缓存首次打开会自动迁移，不用手动清
* **清理缓存保留听书音频**：清书缓存不会把你下载好的音色朗读一并删掉
* **章内翻页只写一条进度**：翻一页不再整表落盘，掉帧更少；退出应用、切后台会立刻保存

### 修复

* 开启「首行缩进」后页尾文字被切掉/错位（测量与渲染现在用同一套缩进）
* 搜索、换源、收录数统计改为统一并发上限，不再一次性打十几个请求
* 「我的 → 关于」里的版本号与本安装包一致，检查更新不会误判（之前个别构建漏了版本注入，会显示成 1.0.0）

### 安卓安装包为什么这样分（体积说明）

V1.0.3 起按架构分包，按你的手机选一个装即可：

|你的设备|选这个|体积|
|-|-|-|
|绝大多数安卓手机（2016 年后，64 位）|`ShuangYue-v1.0.3+9-arm64-v8a.apk`|约 24 MB|
|老机型 / 32 位系统|`ShuangYue-v1.0.3+9-armeabi-v7a.apk`|约 22 MB|
|电脑上的安卓模拟器|用源码自行构建 x86\_64 包|约 26 MB|

> 不确定手机是哪种？装 `arm64-v8a` 那个基本不会错；如果提示"应用未安装"，再换 `armeabi-v7a`。
> 换包安装不会丢数据（同一签名、同包名，直接覆盖）。
