## 爽阅 v0.0.3

**功能更新版。**

### 新增

- **书内搜索**：阅读器顶栏新增 🔍，离线搜索章节标题与已缓存正文，命中高亮、点结果直接跳到那一段（翻页模式按段落探针定位页码，滚动模式复用听书的段落跟随）
- **追更提醒**：书架右上角「检查更新」，连载有新章的书封面挂红色「更新 +N」角标，打开书即消；进书架时距上次检查超过 6 小时会自动补查一次。单本失败不拖垮整轮，本地书与无基线的书自动跳过
- **成就徽章**：连续阅读 3/7/14/30 天、累计 10/50/100 小时、读完 1/10/50 本共 10 枚徽章；达成时桌宠小墨报喜并加经验，统计页新增徽章墙（未达成灰显，悬停看条件）。老用户升级时已达标的里程碑静默回填，不补开庆祝

### 优化

- **推荐页随机混排**：每次刷新各书源随机贡献一半到全部的书目并重新交错，大部分刷新的推荐构成都不一样
- **搜索进度条**：22px 厚色块改为 3px 通栏细线，进度数字由结果区与列表底部行显示
