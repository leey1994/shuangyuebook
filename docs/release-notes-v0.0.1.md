## 爽阅 v0.0.1

**爽快阅读，想看就看。**

全新开始的第一版。

### 宣传语

「爽阅 —— 爽快阅读，想看就看」。App 开屏、官网首页、官网开屏页三处同步换成这一句。

开屏页铺满整个窗口，桌面端连自绘标题栏一起盖住；桌面端固定横版，移动端按屏幕方向自动切换横竖版。

### 桌宠「小墨」

- 四种形态随阅读时长自然成长：**墨滴 → 纸兽 → 墨狐 → 书灵**，全程是同一个角色
- 阅读时钉在顶部窄带，不打扰正文；其余界面在整屏范围内自由溜达
- 会绕开屏幕挖孔（前置摄像头），挖孔类型在「设置 → 桌宠」里选
- 会呼吸、会眨眼，没人理它也自己玩
- 61 种触发状态、300 多条台词

### 书源与阅读

- 内置 **9 个固化书源**：顶点小说、速读谷、黄金屋、52书库、神文小说、素书卷、篱笆好文学、小原文学、全本小说网
- **可导入书源**：支持「阅读 3.0」格式，粘贴 JSON / 选择文件 / 订阅链接三种方式。导入区默认为空，书源由你自己挑
- **书源体检**：导入后自动验活，搜不出内容的直接移除并逐条说明原因
- **本地书**：TXT 与 EPUB，与在线书走同一条阅读、缓存、书签通路
- 四种翻页、行距字距主题、护眼背景、离线缓存、整本下载与断点续传、换源续读
- 在线音色听书
