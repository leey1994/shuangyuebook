# v1.2.1 更新说明

这一版修掉几个看得见的问题，安卓顶部尤其。

## 修复

- **安卓顶部多占了一条空白带**：之前顶部是「系统状态栏 + 桌宠窄带」两条叠加，合计约 56px，看上去像整个顶部被顶下去了。现在安卓全程 edge-to-edge，应用画到状态栏底下，窄带**就是**状态栏本身那一行 —— 原来显示时间 / 信号强度的地方 —— 顶部只占一层
- **Windows 最小化 / 最大化 / 关闭按钮不显示**
- 宽屏下长卡片铺满整行，进度条被拉成横贯卡片的长线
- 桌宠气泡改到身旁显示，不再压在头顶；锚在窄带上沿往下长，不会被窗口上沿裁掉

## 改进

- 桌宠会沿顶部预留带随机散步，走路时整只按方向翻面
- 桌宠会自己玩：没人理它也跳两下、翻个身、伸懒腰、打哈欠、抖一抖
- 61 种触发状态、300 多条台词随机取用，同一个动作不会反复撞同一句

## 升级提示

- 安卓这版顶部布局变了，如果之前觉得顶部空太多，现在应该正好
- 不需要任何操作，装上即可；本版本不新增任何权限申请
