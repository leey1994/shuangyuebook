# v1.2.0 更新说明

这一版给爽阅找了个伴：一只住在顶部的小兽，会因为你做的每一件事而变化。
顺带把安装包瘦身、把书架收拾干净。

## 新增

### 桌宠「小墨」

- 顶部常驻一只小小的书页精灵，四种形态随阅读时长自然成长：墨滴 → 纸兽 → 墨狐 → 书灵
- 全程同一个角色：无论长到哪一形态，水滴头、页角耳、额头的朱红印都不会变
- 会呼吸、会眨眼、被摸会弹一下
- **按场景说话**：按时段问候、久别重逢、久坐护眼、摸鱼提醒，浮出半透明气泡
- 会关心人：深夜劝你睡、久坐提醒眼睛、长时间没来先问你还好不好，不催更不施压
- 常驻顶部预留带，安卓在状态栏下方、桌面在标题栏里，任何页面都在

### 全局联动

- 37 类操作全部接入桌宠：翻章、书签、换排序、搜索、导入书源、换主题、朗读、清缓存……
- 每个动作都有对应的表情与台词，不是简单加个数字
- 同一动作短时间内重复触发只长数值不重复刷屏

### 书架两种卡片

- 简化为「长卡片」与「正方形卡片」两种样式，都带阅读进度条
- 列宽与间距自动计算，卡片间距与两侧留白完全相等，横向永远正好铺满
- 进度条宽度受卡片约束，不会顶到边缘或溢出圆角

### 在线正文字体

- 「霞鹜文楷」改为按需在线下载，不再随安装包分发
- 首次选择时先询问，确认后才下载；下载一次之后长期保留，可离线使用
- 多线路回退，下载失败不影响阅读，自动继续使用系统字体

## 改进

- 安装包体积从 30.2 MB 降到 22.4 MB（-26%）
- 进入阅读器优先读缓存，弱网下不再长时间空转
- 滑到章节末尾继续拖动即可直接进入下一章，不必再点「下一章」
- 桌面端与安卓端的状态栏配色统一，不再出现深浅割裂
- 读到最后一章末尾会记一次「读完一本」
- 书源导出后桌宠会给出反馈

## 修复

- 隐藏状态栏时正文顶部留白不足，文字贴边
- 滑动翻页在章节末尾卡住，翻不到下一章
- 弱网下打开书籍长时间停在加载中
- 启动图标存在叠影，边缘发虚
- 清空搜索后仍在进行的那轮搜索会冒出旧结果
- 换源后阅读进度对齐异常

## 升级提示

- 桌宠可在「设置 → 桌宠」关闭，不喜欢可以直接关掉，不影响任何功能
- 「霞鹜文楷」首次使用需要联网下载约 13 MB；不下载则继续使用系统字体
- 本版本不新增任何权限申请
