## 爽阅 V1.0.2

**书源引擎补全 JS 一脉：JS 书源不再是"摆设"，56 源实测目录可用 36 → 48、正文可用 30 → 43。**（覆盖安装即可升级，书架、书源、进度、缓存全部保留）

### 书源引擎 · JS 引擎与 java.* 桥（本轮主修）

* 内置 **JS 引擎**（Windows 降级 / Android 真 JS 双轨）：`@js:`、`<js>`、JavaScript 型书源从"整行丢弃"变为**直接可用**——QQ 阅读系 8 源（企鹅浏览、球球览器、QB 男生 / 女生等）此前正文一页都取不到，现在**单源 2600+ 章全量可读**
* 内置 **`java.*` 兼容桥**：`java.ajax` / `java.put` / `java.get`、`org.jsoup.Jsoup.connect`、`JavaImporter` 哑对象等按「阅读 3.0」公开行为逐项对齐；**强 JS 书源晋江文学城全链路打通**（搜索 → 目录 127 章 → 正文 1600+ 字），DES / CBC / PKCS5 加解密、`Base64`、`String.getBytes` 等加解密调用内置可用
* JS 源码里嵌的 `{{...}}` 模板（晋江 `num='第{{$.chapterid}}章'` 这类写法）按条目上下文预渲染后再执行

### 书源引擎 · 请求选项与变量持久化

* **网络请求选项**对齐「阅读 3.0」`AnalyzeUrl`：书源地址尾缀 `,{...}`（method / headers / body / charset，含单引号、尾逗号等宽松写法）正规拆解派发；body 对象自动 JSON 化走 POST，`application/json` 默认头，PHP 表单站护航不动
* **变量跨章持久**：`@put:{...}` 写入的变量在后续章节 `@get:{...}` 读回（此前仅当章内存），17k 等靠变量传 bookId 的源从 **目录整空 → 269 章可读**
* 修复 WebView 型章节地址（`,"webView":true` 尾缀）在进 WebView 前未剥离导致的解析失败

### 阅读器 · 翻页手感修复

* **章末轻划松手即进下一章**：整章拖着滑、慢滑松手都能翻（此前只有点右侧翻页和费劲攒 0.3 屏拖动两条路）
* 修复翻页到章节边界**停住半屏、过一拍才跳回**：越界翻页自动回弹到边界
* 覆盖模式"钉住页"改为一帧一跟手：翻页裁剪切线全程贴着手指走，不再半截卡顿
* **音量键翻页（安卓）**：音量下 = 下一页、音量上 = 上一页，按住不连翻、音量条不弹；听书时自动让位给系统音量调节。原生键事件直接拦截（含部分 ROM 不走 Flutter 键通道的机型），翻页零延迟

### 首页 · 书架 · 本地书

* **推荐流页内选源**：来源药丸行与搜索页同款交互，点一个源只看它，点「全部来源」恢复聚合（无需再去书源管理里调勾选）
* 书架**长卡片视图一行一卡**、封面加宽：长书名不再截断
* **EPUB 多级目录**：EPUB2 NCX / EPUB3 nav 的嵌套层级完整解析并在目录中呈现（卷行加粗、章按层级缩进），代码借鉴 foliate-js / epubx 的 TOC 树口径
